# 📐 Kpt2Pose 项目主入口 (`main.py`) 技术文档

**作用:**
`main.py` 是整个项目的核心控制台脚本 (CLI Entry Point)。它负责根据命令行参数（如 `--mode`, `--epochs`）调度模型的完整生命周期：**数据加载 -> 训练 -> 评估 -> 保存权重/指标**。它充当了一个高层级的工作流协调器，将数据加载 (`data_loader`)、模型初始化 (`model`) 和训练过程 (`trainer`) 串联起来。

**核心功能模块概览:**

### 1. 配置管理与初始化 (Initialization)
*   **配置源**: 优先从 `config` 模块读取全局参数（如数据集路径、批次大小、最大 Epoch 数等）。
*   **鲁棒性增强**: 当找不到 `config.py` 时，脚本会自动降级使用硬编码的默认值，确保项目可以以“低质量模式”启动，提高了可移植性和容错性。

### 2. 工具函数 (`export_results`)
此函数封装了数据导出逻辑，用于将训练指标或推理样本等结构化数据保存到本地文件系统。
*   **支持格式**: 支持 `csv` 和 `json` 两种主流格式。
*   **鲁棒性增强**: 加入了对空数据和未知导出格式的检查，确保导出过程稳定可靠。

### 3. 主流程调度 (`main()` function)

#### 🚀 Mode: `train` (训练模式) - *核心流程增强点*
该模式执行完整的模型从零到一的训练周期，并包含关键的评估和报告步骤：
1.  **组件实例化**: 初始化 `DataLoader`, 模型结构, 和 `Trainer` 对象。
2.  **训练循环**: 运行指定 Epoch 数的优化过程 (`trainer.train`)。
3.  **模型评估 (Evaluation)**: **(⭐⭐⭐ 重构重点 ⭐⭐⭐)** 调用增强后的 `trainer.evaluate()` 方法。该方法现在不仅打印结果，还会返回一个包含 **MSE, MAE, RMSE** 等三个核心指标的结构化字典。
4.  **权重保存**: 训练完成后，模型参数通过带时间戳的版本控制机制进行持久化保存 (`trainer.save_weights`)。
5.  **指标导出**: 如果设置了 `--export-metrics` 参数，则将 `val_metrics` (包含全部核心指标) 安全地提取并导出为 `training_metrics.json` 文件。

#### 🔎 Mode: `predict` (推理模式) - *流程优化点*
此模式用于加载最新的、已训练的模型权重并进行一次虚拟运行测试：
1.  **模型版本管理**: 通过 `glob` 和文件修改时间 (`os.path.getmtime`) 自动检测出项目目录下最新版本的模型权重路径，解决了硬编码模型路径的痛点。
2.  **加载与推理**: 加载最新的模型权重并运行模拟数据进行前向传播测试。
3.  **样本导出**: 如果设置了 `--export-sample-data` 参数，将输入特征和预测结果打包并导出为 CSV 文件。

#### ❓ Mode: `help` (帮助模式)
用于展示命令行参数的用法和指导开发者如何正确启动训练或推理流程。
